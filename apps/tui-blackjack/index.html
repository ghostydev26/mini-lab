=== BLACKJACK TERMINAL COMMAND MANUAL ===

KEYBOARD SHORTCUTS:

  • [Space] or [Enter]: Deal hand / Start next round
  • [H]: Hit (draw another card)
  • [S]: Stand (hold current total)
  • [D]: Double Down (double bet, get exactly 1 card)
  • [P]: Split (split pair into 2 hands)
  • [R]: Surrender (forfeit half bet)
  • [1] - [4]: Add bet (+$5, +$25, +$50, +$100)
  • [C]: Clear bet ($0) | [A]: All-In
  • [T]: Cycle theme (Green, Amber, Cyan, Classic)
  • [O]: Toggle CRT scanlines
  • [M]: Toggle SFX audio

TERMINAL COMMANDS:

Type in the CMD input: hit, stand, double, split, deal, bet 100, allin, clear, reset, theme amber, sfx, crt.


RULES:

  • Blackjack pays 3:2.
  • Dealer stands on 17.
  • Shoe auto-reshuffles when cards run low.
