[01] ZERO-CLOUD LOCAL NETWORK (LAN) ARCHITECTURE

VAULT-COM is an air-gapped, zero-cloud communication terminal. It operates strictly within your local Wi-Fi / Ethernet subnet:

• Zero External Servers: No cloud dependencies, no trackers, and no WAN leakage. Messages never touch the public internet.
• Ephemeral Memory: All communications reside in a 100-entry in-memory ring buffer on the host daemon. When the server powers down, all message history is permanently wiped.

[02] HOW TO CONNECT FROM OTHER DEVICES

Any phone, laptop, tablet, or handheld console on the same Wi-Fi or LAN can join instantly:

1. Ensure the secondary device is connected to the same Wi-Fi router.
2. Open Chrome, Safari, Firefox, or Edge on the device.
3. Navigate to either:
  • http://vaultcom.local:8080 (Automatic mDNS broadcast)
  • http://<HOST-IP>:8080 (e.g. check the Subnet IP printed in your terminal header)
4. A unique RobCo terminal handle (e.g. OVERSEER-1, VAULT-GUARD-2) is auto-assigned upon handshake.

[04] ROBCO HACKING PUZZLE MANUAL (BRACKET MATCHING)

The hacking terminal replicates the classic Fallout terminal puzzle:

• Password Likeness: When you pick a word, the terminal tells you how many letters match the secret password in both letter and exact position.
• The Secret Bracket-Matching Mechanic: Look through the memory garbage for matching pairs on the same row: (...), [...], {...}, or <...>.
• Clicking a bracket pair will either:
  1. REMOVE A DUD: Erases an incorrect word and replaces it with dots (......).
  2. REPLENISH TRIES: Resets your attempts remaining back to 4/4!
• Cracking the terminal unlocks temporary Overseer Administrator status and announces the bypass to all nodes!

[05] AUDIO & CRT EMULATION CONTROLS

The display runs a hardware-accelerated CRT raster shader featuring phosphor bloom, 60Hz micro-flicker, scanline grid, and centered 4:3 cathode-ray tube proportions. All sounds (mechanical switch snaps, FSK teletype chirps, 60Hz transformer mains hum, and alarm klaxons) are 100% synthesized in real time using the Web Audio API without any audio file downloads.
